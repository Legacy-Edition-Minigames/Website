  Welcome back, We've been working on the new submission system for ModTools (our custom map system) to allow players to submit custom maps to the server.

  We are finally ready to open submissions for custom maps again! These maps currently are **only on the experimental server**, this will change in the future but it will be quite a bit until that changes.

  If you want to start working on making your own custom map, go ahead and read our [documentation](https://docs.legacyminigames.net)!

  # Important notice
  Make sure that you read the documentation carefully! There are important requirements you **must** follow for your map to be compatible with the server.
